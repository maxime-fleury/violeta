# Crédits et attributions

## Code et contenus originaux

Le code de Violeta, les 76 dialogues, les récits, les points de grammaire, les
tests, les transcriptions françaises et les quiz sont originaux et publiés sous
licence MIT (voir [LICENSE](../LICENSE)).

## Compréhensions orales — CC BY 4.0

Les 16 extraits vidéo proviennent de **Spanish Proficiency Exercises**, une
collection du **Center for Open Educational Resources and Language Learning
(COERLL)**, University of Texas at Austin.

- Collection : https://www.laits.utexas.edu/spe/
- Licence : [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
- Auteur : COERLL, University of Texas at Austin

**Modifications apportées** : les clips ont été réencodés et compressés (H.264,
480p, audio mono) pour un usage hors ligne, une vignette a été extraite pour
chacun, la transcription espagnole a été complétée d’une traduction française,
les glossaires et les quiz ont été écrits pour Violeta. Les vidéos ne sont pas
remontées et les propos d’origine n’ont pas été modifiés.

Aucune affiliation avec l’Université du Texas n’est suggérée : Violeta est un
projet indépendant qui réutilise le matériel dans les termes de la licence.
